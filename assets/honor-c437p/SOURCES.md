# DUDU Honor Gallery — C4.37P

Twenty original, transparent, AI-generated title insignia, packed four per
atlas to minimize phone network requests. Artwork is cosmetic; ownership,
title names, achievements and reward rules remain in the canonical Honor catalog.

Generation mode: built-in `image_gen`; use case `stylized-concept`.
Style brief used for all atlases: premium hand-painted dark-fantasy 3D collectible
miniatures, precious metal and gemstone materials, readable icon silhouettes,
transparent background, centered 2×2 quadrants, no text or watermark.

Atlas transformations: original transparent PNGs were proportionally resized,
padded to 1024×1024 and converted to WebP quality 80. Each CSS badge uses one
quadrant; a title's identity is fixed by its immutable `id`.

Secret locked titles receive no art identifier in the DOM. Other locked titles
use subdued grayscale silhouettes. No earned state is inferred from artwork.
